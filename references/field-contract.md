# 表格字段契约

参考模板列名如下。创建前先读取现有表，不重建用户表，不改不相关列。超链接可以采用文本字段的 URL 样式。原始数组和描述字段按实际需要增加，不要求所有流程复制完全相同的表。

| 默认列名 | 类型 | 用途 / 新建赋值 |
|---|---|---|
| 任务标题 | 文本 | task_name；`fields.title` |
| 飞书任务 ID | 文本 | task_id；`fields.source_task_id` |
| 飞书空间 Key | 文本 | project_key |
| 来源唯一键 | 文本 | 空间 + `:task:` + task_id；`fields.source_key` |
| 所属需求 ID | 文本 | work_item_id；`fields.parent_id` |
| 所属需求名称 | 文本 | work_item_name；`fields.parent_name` |
| 所属节点 ID | 文本 | relate_state_id |
| 所属节点名称 | 文本 | relate_state_name；`fields.node_name` |
| 任务状态 | 文本 | 未完成 / 已完成 / 已删除；`fields.state` |
| 任务状态原始值 | 数字 | 已核验的来源状态值 |
| 负责人 Key | 文本 | 已实际匹配的目标用户 Key |
| 负责人有效 | 复选框 | true；人员变化后保守置 false |
| 来源已删除 | 复选框 | false；删除事件后 true |
| Linear 创建已尝试 | 复选框 | false；发送请求前 true；`fields.create_attempted` |
| Linear ID | 文本 | API 返回的 Issue ID；`fields.linear_id` |
| Linear URL | URL 文本 | Issue URL，显示 identifier |
| 飞书链接 | URL 文本 | 真实父需求详情链接 |
| 最近事件 UUID | 文本 | 事件跟踪，不单独当作业务唯一键 |
| 最近事件时间戳 | 数字 | 来源时间，参考初始 created_at；模板后续分字段推进，不把此列当作总水位 |
| 最近名称事件时间戳 | 数字 | 名称事件水位 |
| 最近状态事件时间戳 | 数字 | 状态/删除事件水位 |
| 最近负责人事件时间戳 | 数字 | 人员事件水位 |
| 同步错误 | 文本 | 可读提示，不记录密钥或完整敏感 payload |
| 同步状态 | 单选 | 待同步、同步中、已同步、失败、待核对、停止同步 |

表的 primary 列可以使用任务标题；已有默认主列不影响逻辑，不要为了美观删除用户数据。模板不依赖额外主列或“任务标题 JSON”公式列。

## 判断语义

- 创建查重：参考模板在独立单空间任务表按 task_id 查询。共享多空间/多类型表时必须改为完整来源唯一键或三个来源字段联合匹配。
- 名称/状态/删除：查到唯一来源行，负责人 Key 正确、有效、未删除；该类事件时间更新，且不早于最近负责人事件。参考模板的删除沿用状态水位；如果业务还要求删除晚于任何字段事件，需扩展对应时间比较。
- 负责人变化：按 task_owners 中的具体任务 ID 与空间匹配；旧人员事件不覆盖新水位。模板不自动处理重新转入，即使仍是本人也暂停，核对后人工恢复。
- 无映射删除：没有 Linear ID 且从未尝试创建时，仅保留 tombstone，不新建 Canceled Issue；创建结果不确定时先核对，已有 ID 时才更新为 Canceled。
- 出表：待同步 + 目标空间 + 目标负责人 + 负责人有效。先标记待核对/已尝试，再分支；无 Linear ID 且已尝试时阻止再次创建。
- 并发界限：Find→Add、标记→HTTP、HTTP→回写均不是跨系统原子事务。快速连发更新可能使下游请求乱序，人员转出也不能取消已发出的请求。对严格并发唯一性/实时权限要求，需平台提供原子条件写或队列等能力，重新评估“无需额外服务”的约束。
